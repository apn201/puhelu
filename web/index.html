Puhelu

An old telephone that rings at night. Whoever answers is placed in a phone menu run by something with a memory. Hang up and it calls back.

This is the web version of a real phone: an Arduino UNO Q and an AG1171 line interface driving a 1950s handset. Same engine, same decoders, no hardware needed.

Sound on. Headphones help. Your state is kept in this browser only.

The line is quiet.

Lift the handset (click it, or press Space). Drag a finger hole round to the metal stop and let go, or type a digit.
